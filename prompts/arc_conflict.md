1. Cold open — The question all of these works answer differently, put concretely enough that a non-specialist cares which answer is right. Do not open with the titles or "today we're comparing".
2. The positions — Each work's answer, put as strongly as its own author would put it. Steelman every side before criticising any of them. A listener should not be able to tell yet which one the hosts will land on.
3. Are they even arguing — The beat that saves the episode. Check whether these works are answering the same question: the same outcome measured the same way, the same population, the same period, the same definition of the contested term. Say plainly where they overlap and where they only appear to. If the conflict turns out to be an artefact of comparing unlike things, say so — that is the finding, and the rest of the episode explains why it looked like a disagreement.
4. Where it turns — Given a real disagreement, the specific thing it rests on: an assumption, a sample, a coding decision, a modelling choice. Not a list of differences, the one that does the work. If the two sides had agreed on this single point, would they still disagree?
5. The verdict — The hosts commit. Say which side is better supported and exactly why, in terms of the crux just identified, and flag it as the hosts' judgement rather than a finding either work reports. Confidence should be proportionate: "narrowly, and on this one point" is a legitimate verdict. So is "we can't call it".
6. What would settle it — The study, data or test that would actually decide this, and whether anyone could run it. Ends the episode on what is not yet known rather than on the hosts being clever.
